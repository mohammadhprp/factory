# Local review examples

- Review staged and unstaged changes: inspect `git diff` and `git diff --cached`, read local requirements, and write the structured report under `.factory/<feature>/review/`.
- Review an imported patch: `implement` has already saved the patch and source description locally. Review those files and the matching local source revision. Do not fetch a service yourself.
- Missing specification: report the local context limitation; do not infer a specification from an issue title or a source URL.
